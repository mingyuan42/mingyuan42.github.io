第2部分 · 升级你的操作系统 · 第 08 课

万能钥匙：钥匙一定在别处；以及删掉「坚持」和「毅力」

阅读约 13 分钟·李笑来 · 得到专栏第一季·仅供学习，不构成投资建议

本课目标：掌握「锁头—钥匙」思维模型，学会把注意力从问题本身移开；理解为什么「坚持」「毅力」是应该从大脑操作系统里删除的概念；学会用「赋予意义 + 社交化学习」让行动停不下来。

对应原书：第 11 篇《"万能钥匙"》（2016-10-14）、第 12 篇《"坚持"与"毅力"》（2016-10-21）。

一、锁着的门，钥匙不在锁孔里#

当你遇到一扇被锁着的门，你应该去哪里找钥匙？

显然不是盯着锁头看。如果锁孔里插着钥匙，那门等于是开着的。 之所以打不开，恰恰因为钥匙在别的地方。

把这个类比迁移到问题上：

  • 问题 = 被锁上的锁头；
  • 解决方案 = 钥匙；
  • 结论：钥匙一定不在锁孔里，一定在别的什么地方。

所以只盯着问题看、盯着问题想、盯着问题找解决方案，通常只能以无奈告终。这是用蛮力解决问题。

而现实生活中，我们的注意力除了被娱乐新闻占据，还有很大一部分被「困扰我们的问题」占据——投入大量注意力却收效甚微，就是因为关注点全在问题本身。

这里元认知能力（第 07 课）派上用场。一旦发现自己正在「只盯着问题本身思考」，就让它弹出提醒：

不对，我得把注意力从问题本身移开，因为解决方案肯定在其他地方……

有位读者的比喻很好：调用元认知能力就像系统的「自弹窗口」。知道原理、知道训练方法还不够，最重要的是让它成为本能反应——就像渴了找水、饿了找吃的一样自然。

你虽然升级了操作系统，但是不去使用，或者只用过去系统的功能，对新功能不闻不问，那和没有更新其实一样，甚至更糟。

二、四个「钥匙在别处」的实例#

锁头（问题） 大多数人盯着的地方 真正的钥匙
伴侣突然生气 就事论事地反复解释那件事 X 让对方极度开心（情绪对立，不可共存）
英语听力差 拼命地「听」 说——只要说得出，就能听得懂
时间不够用 管理时间 管好自己：先做正确的事，再找正确的方式
赚不到钱 盯着钱 盯着自己的能力成长

实例 1：情绪的钥匙#

作者说他在心理学书籍里找到了这把钥匙：

对人类这种高级动物来说，有些情绪是对立的，几乎完全不可能共存。你几乎没办法既高兴又痛苦，既兴奋又低落，既无聊又觉得有趣。

于是解法简单明了：要是能让对方感到极度开心，TA 就没办法痛苦、生气、无聊、无奈。

那么真正的功课是什么？

你平时花足够的时间思考过这件事吗——究竟都有哪些东西、哪些事件可能让对方极度开心？

从没花心思想过这些的人，怎么可能顺手就掏出一把钥匙？大多数人一生不做这样的思考，总是临时抱佛脚——佛脚上根本就没有钥匙串。

（作者特意说明：这里的小男生/小女生只是指称，两个词调换过来也是一样的事实，与性别没有必然的逻辑锁定关系。另外别觉得恋爱与财富无关——能长期开开心心地相处，就省出大量用来伤心难过的时间去做正事。）

实例 2：听力的钥匙是「说」#

只要说得出，就能听得懂。这是放在哪门语言上都通用的道理。

你甚至不需要说得标准。就像我国很多地区的人普通话并不标准，但几乎没人抱怨听不懂新闻联播。所以练「说」就够了，没必要专门练「听」。

实例 3：《把时间当作朋友》的诞生#

想明白了要做事，却发现时间不够用——这是所有人都面临的问题。但「管理时间」解决不了它。于是调用元认知把注意力移开，很快找到钥匙：

管好自己就行了。想办法做正确的事情，这个最重要；然后再想办法找正确的方式。哪怕方式错了也无所谓，毕竟可以修正；哪怕效率低一点也可以接受，毕竟只要做了就有积累。

实例 4：赚钱的钥匙#

民间早有观察：你追钱，追不上钱；钱追你，你跑不掉。

作者 2005 年开始在网上写博客时，网上写字根本赚不到钱，连注意力都收割不到多少。那时他们靠最朴素的方式在别处赚钱（出售时间、提高时间单价），来供养自己「有点兴趣、看起来不务正业」的事。

十多年后，互联网连接了所有人，移动支付成本几近于零，内容变现成了趋势，善于创作、精于制作、又会传播的人「轻松地」赚到了钱。

背后仍是那把万能钥匙：

别人都盯着钱看，我也觉得钱是个问题，但我觉得解决方案一定在其他地方……最终我认定能力更重要，盯着自己的能力和能力成长才是真正的钥匙。

所以这个「财富」专栏几乎不谈钱：

总盯着钱的人，通常赚不到钱。真正赚到钱的人，通常都会把注意力放到自身能力的提高上。

更多可以立刻套用的例子#

  • 英文遇到瓶颈 → 想背海量单词？钥匙可能在别处：他们的母语（语文）就很差。
  • 孩子没耐心 → 钥匙在别处：父母自己就没有耐心，孩子在复制父母的行为。
  • 觉得「世界太不公平」 → 很可能不是世界的问题，甚至不是公平的问题，而是是否配得上被公平对待的问题。

三、你需要一个「锁头本」和「钥匙本」#

很多人说自己没有积累，找不到合适的钥匙。作者指出两个具体缺口：

  1. 没有「找钥匙」的概念：即便读到「有些情绪不可共存」，也不会想到把它用到恋爱矛盾上。
  2. 没有记录：即便有了意识，如果不及时记录自己遇见的「锁头」，碰到合适的钥匙时已经忘了当初的问题是什么。

所以要养成双向记录的习惯：

记录什么 为什么
遇到的每一个「锁头」（未解决的问题） 以后遇到钥匙时能对上号
遇到的每一把「钥匙」（有用的原理、方法、事实） 以后遇到锁头时能翻出来试
定期回顾总结 减少「忘记找钥匙」和「有钥匙忘了锁」的情形

补充里那句是这套方法的能力基础：你平时涉及的领域越多、在每个领域了解得越深，你就越有可能找到更多且更优质的钥匙——这正是第 06 课多维竞争的另一种表述。

四、把「坚持」和「毅力」从操作系统里删掉#

现在用刚学的万能钥匙来处理一个新锁头：为什么你总谈「坚持」「毅力」，却从来没有持续做好一件事？

钥匙在别处：问题不是你没有毅力，而是这个词压根就不应该出现在你的操作系统里。

同构的错误概念还有一串：

脑子里的概念 于是你只会想 于是你忽略了
时间管理 如何管理时间 如何管理自己
快速阅读 读得太慢 认真思考
坚持 / 毅力 如何摆脱痛苦 换个角度，这件事或许可以变成快乐的事

作者的核心判断：

若是某件事你觉得需要努力、需要坚持才行，那这事儿基本上从一开始就注定做不成了。需要努力、需要坚持，说明你骨子里不愿意做。

（「骨子里」不完全是比喻——底层反应来自内脑与脊髓连接处，确实是大脑深处。相比之下「内心深处」是个相当落后的概念。）

为什么痛苦会导致放弃：大脑会遗忘痛苦#

  • 我们的大脑有遗忘痛苦的功能；回想过去的痛苦，你能想起来的并不多，时间越久越模糊。
  • 越痛苦的事情通常遗忘得越快，这是大脑为了保护我们进化出的功能。
  • 而学习知识、打磨技能，本质上都是要在大脑里留下痕迹。
  • 如果你从一开始就给它赋予太多痛苦，大脑自然会想方设法帮你抹掉这部分记忆。

所以想要不放弃，首先就不要给自己「痛苦」的暗示。

五、替代方案一：赋予重大的意义#

作者磨炼出的策略：

无论做什么事情，在开始之前，都要想尽一切办法为这个事情赋予重大的意义，甚至多重重大的意义。

案例 A：专栏收入全部捐作奖学金#

以他的情况，用写文章赚钱很难有动力。于是他决定：专栏所有税后收入捐出去，设立鼓励大学生学习计算机知识的奖学金。

接下来发生的变化是：大脑高度兴奋、注意力高度集中、创意层出不穷。因为他算了一笔账：

换算 数值
当时订阅量下的单位收益 约每字 100 元
一个二三十字的句子 ≈ 2,000 元 = 资助一名优秀学生一年
一篇约 2,000 字的文章 ≈ 帮助 100 名大学生

「这动力肯定是不一样的。写着写着写高兴了，就不管字数了，超出一点就超出一点罢。」

案例 B：背单词 = 赚钱#

当年为了进新东方教书要考 TOEFL/GRE，要背两万多个单词。第一反应也是「这哪儿是人干的事」。然后他花了一个下午琢磨怎么赋予意义：

  • 考高分 → 进新东方 → 据说年薪百万 → 一个单词相当于 50 块钱。
  • 原计划每天背 50 个适应一下；想到这层立刻改主意：第一天就要赚 5,000 元。
  • 第二个月不过瘾，改成每天「赚」1 万元，试试发现也不太难。

后续的真实结果也很诚实：真去了新东方才发现年薪百万是扯淡，讲课加写书好不容易做到税后年薪 50 万，在那里赚了七年——算下来每个单词粗略相当于 175 块钱。

意义是个人化、阶段化的#

同样的事情，不同的人能赋予的意义不同；同一个人在不同阶段能赋予的意义也不同。

对那时的他，每天挣 50 块是重大意义；对你，可能是考入梦寐以求的大学。重要的不是把关注点放在别处，而是找到当下对自己最重要的意义，并把它均摊到每天的任务上。

结果不是坚持，是停不下来#

一念一世界。在我们这种人的世界里，这不是苦哈哈的坚持、臭哄哄的努力，这是干脆停不下来啊！谁敢拦着我我就跟谁急。

  • 喜欢读书的人多半不是在坚持，读书本身就是享受。
  • 喜欢运动的人多半也不是在坚持，运动产生的多巴胺足以让他们享受。
  • 学会一门技能带来的是重生的快感：你的世界多出一个维度，看到了过去不曾有过的景象，甚至觉得自己又活了一遍。这种快感体会过一次，别人想拦都拦不住。

六、替代方案二：给「没有它」赋予负面意义#

在赋予正面意义之后，还可以反向操作。拿出一张纸，花几天甚至几个月去罗列：

  1. 如果我没有这项技能，现在有什么事我根本做不了、根本没有机会？
  2. 将来会遇到什么样的困难？会失去怎样的机会？
  3. 如果我最终没掌握这项技能，我就跟哪些人一样了？他们的生活因此有多么凄惨？

不仅要罗列，还要展开想象的翅膀，把细节栩栩如生地写下来。

这会「吓到」你的大脑——准确地说，是把那种你所需要的恐惧深深埋入潜意识，然后它就会在很多时候自动工作，催促你赶紧弄，否则它就焦虑、就害怕、就不安生。

一个可直接照抄的例子：每天留言 200 字#

很多人说自己写作能力不够，希望有锻炼机会。留言就是最好的起点：长度适中、已有框架（思考题）、还有大量参考材料（别人的留言）。

算一笔账：

周期 产出
每天 200 字
每周整理一次 一篇 1,000+ 字的阅读笔记
一年 52 篇 ≈ 给自己写了一本书

而且记录的都是自己的成长过程；与此同时操作系统升级了，你能用文字明确表达自己的观点了。单是这几点进步，就足以让你过上另一种生活。

七、替代方案三：社交化学习#

想尽一切办法去寻找拥有某项技能的人以及人群，尽量与他们共度大量时间；如果没办法一对一交流，起码也要时刻关注他们。

社交，从来都是学习活动中的一部分。

反面例子：如果你的朋友都是胖子，你很可能慢慢被「传染」成一个胖子。一是他们对「肥胖」这个概念的理解会影响你；二是半夜他们笑嘻嘻叫你出去吃夜宵「喝点啤酒呗」的时候，你会欣然接受。近朱者赤，近墨者黑。

正面机制：当你与拥有某项技能的人群在一起，你会不由自主地「发现」「感受到」那项技能其实很自然、很实用、没有它根本不行。这些判断上的变化会极大影响你的行为与感受——于是另一个世界里「很艰难、很痛苦、很难坚持」的事，在你的世界里全变成「真好玩、停不下来、要是能多玩一会儿就好了」。

这也是作者办「新生大学」的原因：仅仅相互见得到、相互知道对方的存在，对学习者就是巨大的价值。 背后的科学概念是镜像神经元——这也是学习必然是一种社交活动的根本原因。

八、把两课串成一条行动链#

遇到锁头
  → 元认知弹窗：钥匙不在锁孔里
  → 把注意力从问题本身移开，去别的领域找钥匙
  → 记录锁头与钥匙，定期配对回顾
  → 找到要做的事之后，不要靠「坚持」
      → 赋予多重重大意义（均摊到每天）
      → 罗列「没有它」的负面后果（写细节）
      → 找到拥有该技能的人群，泡在一起
  → 结果：停不下来

本课要点#

  • 万能钥匙：遇到锁头，去别的地方找钥匙；只盯着问题本身是用蛮力。
  • 元认知要成为「自弹窗口」式的本能反应，否则等于系统升级了却不用。
  • 四个范例：情绪→让对方极度开心；听力→说；时间→管好自己；赚钱→能力成长。
  • 总盯着钱的人通常赚不到钱；真正赚到钱的人盯着自身能力的提高。
  • 双向记录「锁头」与「钥匙」，并定期回顾配对；领域越多越深，钥匙越多越好。
  • 「坚持」「毅力」「努力」是应当删除的概念——需要坚持说明骨子里不愿意做。
  • 大脑会遗忘痛苦；一开始赋予痛苦，等于让大脑抹掉学习痕迹。
  • 替代方案：①赋予多重重大意义并均摊到每天；②罗列「没有它」的负面细节；③与拥有该技能的人群共处（镜像神经元）。
  • 目标状态不是「坚持住」，而是「停不下来」。

自测#

  1. 用锁与钥匙的类比解释：为什么盯着问题本身通常解决不了问题？
  2. 英语听力差的钥匙在哪里？依据是什么？
  3. 为什么「总盯着钱的人通常赚不到钱」？
  4. 为什么要同时记录「锁头」和「钥匙」？只记一个会出什么问题？
  5. 从大脑机制解释：为什么「需要坚持」的事往往做不成？
  6. 复述作者背单词的意义换算是怎么做的。这个方法的通用步骤是什么？
  7. 「赋予负面意义」具体怎么做？为什么必须写出细节？
  8. 社交化学习的机制是什么？请举一个你可以立刻执行的例子。
参考答案
  1. 因为如果钥匙插在锁孔里，门就等于开着；正因为门锁着，钥匙必然在别处。同理，问题之所以成为问题，说明解决方案不在问题内部。只盯着问题投入注意力，是用蛮力，通常以无奈告终。
  2. 钥匙在「说」。原理是「只要说得出，就能听得懂」，这对任何语言通用；甚至不需要说得标准，就像很多地区的人普通话不标准，但没人听不懂新闻联播。所以应练说而非专门练听。
  3. 因为钱是结果不是原因。财富来自你为他人创造的价值，而价值来自能力。盯着钱只会消耗注意力却找不到钥匙；盯着能力成长才是真正的钥匙。作者自己的写作变现，就是多年在别处积累能力后趋势到来的结果。
  4. 因为钥匙与锁头往往在不同时间、不同领域出现。只记锁头，遇到有用原理时不会想到去配对；只记钥匙，等遇到问题时已经想不起曾经见过什么工具，或者有了钥匙却忘了当初的问题是什么。双向记录并定期回顾才能完成配对。
  5. 大脑有遗忘痛苦的功能，越痛苦遗忘越快，这是保护机制。而学习本质是在大脑里留下痕迹。如果一开始就把这件事标记为痛苦、需要咬牙坚持，大脑会主动抹掉相关记忆，于是难以积累，最终放弃。
  6. 他把「考 TOEFL/GRE → 进新东方 → 据说年薪百万」换算成「一个单词 ≈ 50 元」，于是每天背 100 个 = 赚 5,000 元，第二个月加到每天「赚」1 万元。通用步骤：①确定当下对自己最重大的意义；②把它量化并均摊到每天的最小任务单位上；③用这个换算结果驱动日常行动。
  7. 拿纸罗列：没有这项技能，现在做不了什么、没机会做什么；将来会遇到什么困难、失去什么机会；最终没掌握的话会和哪些人一样、他们的生活有多凄惨。必须写出栩栩如生的细节，因为这样才能把所需的恐惧埋入潜意识，让大脑在很多时候自动催促你行动。
  8. 机制是镜像神经元与群体规范：与拥有某项技能的人共处，你会不由自主地感到这项技能自然、实用、不可或缺，判断改变进而行为改变；同时学习本身是社交活动。可执行的例子：加入一个每天写作/跑步/编程的社群，定期与成员交流并公开自己的进度；或长期关注几位实践者的公开记录。
