活在未来，并成为别人的贵人活在未来，并成为别人的贵人

本课目标：把「活在未来」从一句口号变成一套可执行的七步流程；掌握最安全的预测策略；理解「遇到贵人」的真实机制，并学会正确地求助。

对应原书：第 04 篇《生活的根基"活在未来"》（2016-08-26）、第 05 篇《遇到贵人的方法》（2016-09-02）。

一、「活在当下」为什么可能是个坏建议#

上一课我们说过：追求百分之百的安全感，会让人被困在永恒的当下。

现在把这条结论推到它的终点。如果一个人只有「当下」，那么他的当下与未来是两个互不相交的时空。更准确地说：

「当下」这个概念并不独立存在，它只有相对于「过去」和「将来」才有意义。

所以一个没有过去、没有未来的人，其实连当下都没有——他只是「就那样存在着」而已。

三种活法的对比：

活法 状态 结果
活在过去 被困在更差的地方 用旧地图走新路
活在当下 被永恒地困住 没有积累，没有方向
活在未来 思维提前抵达结果 提前按正确的结果行动

注意最后一行的限定：肉身只能活在当下，所谓活在未来，本质上只能是「思维上活在未来」。哪怕是「部分活在未来」，也已经是质变。

二、活在未来的七步流程#

听起来玄，做起来极其简单：

  1. 你对未来有一个预测；
  2. 那个预测需要时间才能得到结果；
  3. 你笃信自己的预测是正确的；
  4. 于是你提前按照那个预测的结果去行动、选择、思考；
  5. 你终将走到那个结果出现的时刻；
  6. 最终证明你的预测是正确的；
  7. 于是在相当长的一段时间里，你生活中的一部分就是「活在未来」的。

关键在第 3 步。作者反复强调：「相信」没有用，必须是「笃信」。

为什么大多数人做不到？因为几乎所有人都能说出「知识就是力量」，但大部分人只停留在「想一想」的阶段。更深一层的原因是：

没有做过深入思考，因此无法笃信自己的预测。

而笃信的根基不是盲目自信，而是扎实的推理和不断的拷问。

一个形象的比喻：这就像你知道了下期彩票的中奖号码，你怎么可能忍住不去买？随着思考的深入，「当下」和「未来」的重合会越来越大，到最后你想不活在未来都难。

作者自己的两个例子#

例一：1980 年代中期，初二日记本里的预测

  • 长期来看，脑力的产出率一定比体力高，且高出许多个量级；
  • 体力增长有明显的玻璃顶，脑力增长的玻璃顶不知道在哪儿；
  • 体力衰退来得很早，脑力衰退来得晚很多；
  • 通过暴力可获得的暴利正在减少，知识更可能产生更大的暴利。

这些不是他原创，而是从当时的书报上看来的（「知识就是力量」「科技就是生产力」是八十年代的主流论调）。他做的事只有一件：想清楚它是对的，然后笃信，然后按它指引的方向生活。

二十多年后验证：2005 年读《魔鬼经济学》，发现纽约黑帮赚不到多少钱还要冒生命危险；2013 年认识一批游戏行业的人，感慨九零后程序员写游戏赚钱且无生命危险。他多年来讲课、写书、投资、创业，靠的都是知识——在这个层面上，他确实做到了活在未来。

例二：2015 年上半年得出的五条结论

  1. 貌似消失的各种社群一定会卷土重来；
  2. 新生代社群的数量会超过上一代；
  3. 新生代社群中，免费的将逐步被收费的超越；
  4. 以交易为核心的分享将逐步超越以信息为核心的分享；
  5. 社群的壁垒大抵是收费与内容积累。

于是他跟朋友说「收费时代来了」，几乎没人搭理。他就自己在 2015 年 8 月开了公众号（当时很多人说红利期早过了），10 月底积累约 4 万订阅，11 月开始搭建收费社群，并组建团队做社群工具。

他同时诚实地加了一句极其重要的话：

我的预测并不一定正确。我自己知道自己预测成功的历史数据没多好看。但「不确定性」是不可消除的，于是我只能按照逻辑行事。

如果一两年后收费社群没有成为常态，那他就是「活在了错误的未来」——可那又怎样呢？他早就放弃了百分之百的安全感。

三、最安全的预测策略#

预测是少数人才能掌握的能力，但有一个特别容易且特别安全的策略：

如果某个道理客观上确实正确，过去它成立，现在它还成立，那么不出极大意外，将来它还是成立的。

于是你按这个道理行事，在这个层面上你就活在未来了——你用最简单的策略做出了成功概率最大化的预测。

作者用它推导出的实例：

  • 道理：「做对的事情，远比把事情做对重要得多。」
  • 推论 1：管理时间是没戏的，因为时间根本不听谁的话；对的事情是管好自己。
  • 推论 2：做错了事情，效率越高越可怕；做对了事情，即便拖拖拉拉，只要终于完成，收获也巨大。
  • 行动：写出《把时间当作朋友》。

被大多数人当耳旁风的朴素道理，其实满天飞舞：

朴素说法 现代包装 本质
无它，手熟尔（卖油翁） 一万小时定律 / 精进原理 重复练习带来精通
少壮不努力，老大徒伤悲 复利效应 / 时间窗口 早期积累的指数差异
出来混的，早晚要还 长期主义 / 均值回归 估值终将锚定价值

越是朴素的道理，越是永恒。把它们研究透了，相当于瞬间穿越到未来——因为那些道理在未来依然成立。

关于预测的三条纪律：

  • 尊重事实，相信逻辑。 没有万能公式，能做好这两点已经很不容易。
  • 不要期望一次就预测对。 预测次数足够多，你会发现准确真的很难。
  • 每次失败后总结：哪些数据收集得不够完善？哪些逻辑链条推理得不够缜密？

还有一条心理建设：默认没有人支持你，把别人的鼓励都当作额外赠送的。大部分企图活在未来的人，都会刺激到活在当下的人。

本课最后的预测：活在未来的人一定比活在当下的人拥有更多财富。理由很简单——所谓投资，无非就是用现在的资源换取未来的资源。

四、贵人：先拆掉一个错误概念#

有个流传很广的说法，用智商/情商的组合解释郭靖为什么总有贵人相助。作者的反驳很直接：

  • 智商低下的人不可能有一流的情商；
  • 智商和情商并不冲突，两者都是脑力活动；
  • 他甚至不相信「情商」这个概念有存在的必要——所谓「情商差」，完全可以更清楚地解释为「脑力不够，所以思考不全面不深入，于是出现了意外的不良后果」。

这延续了本书的方法论：遇到含混的流行概念，先把它拆开，用更清晰的定义替换掉。

五、一个真实故事：讨公平，而不是诉苦#

1980 年，作者的父亲在黑龙江海林县一所中学任教，此前曾被关押劳动改造三年，等待「落实政策」。

  • 父亲的反应：得先攒钱，而且去了也不一定能办成，有人在北京折腾半年多还没结果——先算风险。
  • 母亲的反应：第二天晚上说「我把房子卖了，这是人家给的一半定金，车票已经买好了，后天你走，我带两个孩子住到单位去」。

她给父亲买了两套新衣服，叮嘱的话成了这个家庭反复复盘的经典：

咱不是去诉苦的，咱是去讨个公平的。有事儿说事儿，没事儿不啰嗦。

到了北京，你一定要昂首挺胸，不卑不亢，干干净净，利利索索。

到了北京，全国各地来落实政策的人几乎无一例外想用「自己的悲惨」感动工作人员，拄拐杖的、打石膏的，仿佛惨烈可以用来插队。而父亲每天收拾得利利索索去排队。经常遇到的情况是：叫号的人出来抬头一看，就招手说「你，站在那儿干嘛？过来！」

第 35 天，父亲成了海林县第一个成功落实政策的人，也是后来所有成功者里办理最快的。

母亲的原则是：

自己首先得是个贵人，才能遇到贵人，甚至更多贵人。

作者后来在书里写的「你不优秀，就没有有效的社交」，就脱胎于这句话。

由此得到本课最重要的转向：

「遇到贵人」从来不是我们的目的，「成为贵人」才是应该努力的方向。

哪怕运气差到一个贵人都没遇到，你也已经成长起来，并且发现：你已经成为了自己的贵人——而这位贵人不会轻易离你而去，更不会让你失望。

六、十二条贵人原则#

作者在母亲的基础上不断增补，整理出这些朴素但有效的原则：

  1. 乐观的人更容易成为他人的贵人；
  2. 贵人更容易遇到贵人；
  3. 能帮助他人进步的才是真正的贵人；
  4. 优秀的人、值得尊重的人更容易获得帮助；
  5. 乐于分享的人更容易获得帮助；
  6. 不给他人制造负担的人更容易获得帮助；
  7. 不耻于求助的人更容易获得帮助；
  8. 求助时不宜仅用金钱作为回报；帮助他人时不宜收取金钱回报；
  9. 贵人不一定是牛人——牛人常常只是自顾自地牛，贵人更懂得「独贵贵不如众贵贵」；
  10. 很多时候人们的成功源自大量的人希望看到他成功；反之则很难获得相助；
  11. 正在做正确事情的人更容易获得相助，所谓「得道多助」；
  12. 活在未来的人更容易遇到贵人，因为别人能在他身上看到未来。

时间尺度也很重要：这些机理生效不是明天，不一定是明年，但三五年之内你一定有所体会。可惜绝大多数人连三五个月都等不及——大多数人缺的正是「思考长远，耐心验证，小心总结提炼」的能力。

七、求助不是乞讨：四个概念的辨析#

大多数人对「求助」有极深的误解，把它当成低声下气、卑躬屈膝的行为。那不是求助，那是乞讨。

概念 本质 对方的感受
求助 一种隐蔽但意义巨大的交易，展示自我价值 我看到了你的价值和未来的可能性
乞讨 单方面索取，把自己等同于乞丐 负担
添麻烦 把本该自己做的事推给别人 被消耗
占便宜 只为减轻自己的工作、节省自己的金钱 被利用

核心洞见：

贵人之所以愿意帮你，是因为他已经看到了你的价值——要么这种价值帮助他确立自己的价值，要么这种价值让他看到未来的某种可能性。

在你出手相助的那一瞬间，你已经得到了自然的回报。

所以帮助他人从来不是你赢我输，而是共同进步的过程；很多人在帮助你的过程中自己也是受益者，甚至是更大的受益者。

由此得到两个可操作的心态：

  • 求助不是「欠人情」，而是「做交易」，只不过每笔交易不是即时兑现的。这样你就跳出了人情的束缚，转而更关注自己的成长。
  • 要相信贵人的眼光。他选择帮你，说明他认可你、觉得你未来有机会反过来帮他。与其焦虑还不上，不如加一个「暂时」：我只是暂时能力不足、暂时资源有限。

每个人都生活在价值交换与价值集群之中，所有聪明人都会为自己做两件事：储备人际价值、到人际价值高的地方去扎堆。所以求助根本不是讨好的艺术，而是正确展示自我价值的艺术。

八、两个立刻能用的措辞技巧#

有时候改变我们的不是大道理，而是一个能纠正错误观念的小技巧：

把 改成
失败 暂时不成功
讨厌 还没喜欢上

理由很实在：一个时常因为「失败」而气馁的人，无法一路坚持往前走；一个「讨厌」这「讨厌」那的人，无法心平气和地面对负面反馈。

本课补充里还有几条值得抄下来：

  • 「践行」是一个人是否真相信某种理念的体现。
  • 从开始就像专业人士一样生活；最好的学习方式从来不是「学」，而是「用」。
  • 当你还没有取得成绩时，没有人会重视你的建议，这是人之常情——我们自己多半也是这样对待他人的。
  • 不要小瞧自己的声音，所有正确的声音都是这么一点点发出来的。
  • 很多时候阻碍我们行动的不是能力，而是脑子里错误的观念。
  • 想修正「求助 = 麻烦别人」这个偏差，最好的方法是自己多去试着帮助别人，看看这个过程是不是只有麻烦、没有收获。

本课要点#

  • 「活在当下」若意味着没有过去与未来，那就是被困住；必须（哪怕部分地）活在未来。
  • 活在未来 = 预测 → 需要时间 → 笃信 → 提前按结果行动 → 时间验证；肉身仍在当下，思维已在未来。
  • 「相信」不够，必须「笃信」；笃信来自扎实推理与不断拷问，而非盲目自信。
  • 最安全的预测策略：客观正确、过去成立、现在仍成立的道理，将来大概率还成立。
  • 预测必然有错；尊重事实、相信逻辑、多次尝试、每次复盘，默认没人支持你。
  • 遇到贵人不是目的，成为贵人才是；最差的结果是你成为了自己的贵人。
  • 十二条贵人原则的共同内核：乐观、优秀、分享、不制造负担、正在做正确的事、活在未来。
  • 求助是交易而非乞讨；区分求助 / 乞讨 / 添麻烦 / 占便宜；用「暂时」化解人情焦虑。
  • 把「失败」改成「暂时不成功」，把「讨厌」改成「还没喜欢上」。

自测#

  1. 为什么说「只有当下」的人其实连当下都没有？
  2. 完整复述活在未来的七个步骤，并指出哪一步是大多数人卡住的地方及原因。
  3. 最安全的预测策略是什么？请用「做对的事情比把事情做对更重要」演示一次推导。
  4. 作者承认自己预测成功率不高，为什么仍然坚持按预测行动？
  5. 父亲「讨公平不诉苦」的故事，印证了哪一条贵人原则？
  6. 求助、乞讨、添麻烦、占便宜四者的区别是什么？为什么说求助是一种交易？
  7. 为什么「求助时不宜仅用金钱回报，助人时不宜收取金钱回报」？
参考答案
  1. 因为「当下」是相对「过去」和「将来」才有意义的概念。一个不追溯过去、不预测未来的人，其时间没有前后对比，无法形成积累与方向，他只是「存在着」，并没有真正意义上的「当下」。
  2. ①做出预测；②预测需要时间才能验证；③笃信预测正确；④提前按预测结果行动、选择、思考；⑤走到结果出现的时刻；⑥预测被证明正确；⑦于是在这段时间里部分地活在未来。卡在第③步：因为缺乏深入思考，无法笃信，只停留在「想一想」，所以不会真正提前行动。
  3. 策略是：若一个道理客观正确、过去成立、现在仍成立，则将来大概率仍成立，按它行事即等于活在未来。演示：接受「做对的事情远比把事情做对重要」→ 推出时间不可管理，应管理自己 → 推出做错事时效率越高越可怕，做对事即使慢也收获巨大 → 于是把精力用于筛选「对的事情」，并据此写出《把时间当作朋友》。
  4. 因为不确定性不可消除，人只能按逻辑行事；他早已放弃百分之百的安全感。即使某次活在了「错误的未来」，代价可控，而一次成功的活在未来收益不可想象；并且失败本身提供了修正数据与逻辑的材料。
  5. 印证「优秀的人、值得尊重的人更容易获得帮助」以及「不给他人制造负担的人更容易获得帮助」。他不展示惨烈、不制造情绪负担，干净整洁、有事说事，让办事者愿意主动招手，本质上是以自身的体面与清晰展示了价值。
  6. 求助是展示自我价值的交易，对方因为看到你的价值或未来可能性而帮你；乞讨是单方索取、自我贬低；添麻烦是把本应自己承担的事推给别人；占便宜是只为省自己的钱和力而索取。说它是交易，是因为贵人出手的瞬间已获得回报（确立自身价值、看到未来可能性），只是兑现不在当下，而在他未来的成长里。
  7. 因为这种关系的核心是价值与成长的相互确认，而非即时结算。仅用金钱回报会把长期的价值交换降格为一次性买卖，抹掉了「我相信你未来会更好」的部分；助人时收钱则把自己从贵人降为服务供应商，失去看到对方成长带来的自然回报，也削弱了长期的人际价值储备。
